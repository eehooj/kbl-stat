# Daily Picks 리바운드

## 목표와 완료 시각

- 목표: 공식 선수 박스스코어에 이미 저장된 리바운드 합계를 Daily Picks 추천과 백테스트에 연결한다.
- 완료: 2026-11-01 (Asia/Seoul)

## 변경 내용

- `app/services/daily_picks_recommendation.py`
  - 화면 문구에서 분류된 `rebounds`를 지원 지표에 추가했다.
  - 대상 경기 이전 최근 최대 5경기의 선수별 리바운드를 팀·경기 단위로 합산해 경기당 평균을 비교한다.
- `tests/test_daily_picks_schedule_linking.py`
  - 공식 문제 문구의 리바운드 분류 회귀 테스트를 추가했다.

## 실행·검증

```bash
python -m pytest -q
# 40 passed
python -m ruff check app tests
# All checks passed!
python -m app.cli backtest-daily-picks
# 공식 정답 20건 / 평가 가능 14건 / 적중 7건 / 적중률 50.0%
# 평가 제외: 질문 지표 미확인 2건, 최근 기록 부족 4건
```

이전 결과(평가 가능 13건, 적중 6건, 46.2%)보다 평가 가능·적중이 각각 1건 증가했다. 2026-10-28 리바운드 문제는 대구 한국가스공사를 추천했고 공식 정답과 일치했다.

## 외부 데이터와 제한 사항

- 공식 KBL 완료 경기 선수 박스스코어의 브라우저 렌더링 화면에서 수집해 둔 리바운드 값만 사용했다.
- 내부 API는 직접 호출하지 않았다.
- 문제 대상 경기와 같은 시각 또는 이후 경기 기록은 평균에서 제외한다.

## 남은 작업

- 굿디펜스를 공식 문자중계 이벤트로 정확히 집계할 수 있는지 검증한다.
- 득점 우위시간은 공식 문자중계의 전체 득점 흐름과 동점 구간을 재생해 계산한다.
