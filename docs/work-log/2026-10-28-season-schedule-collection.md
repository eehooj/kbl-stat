# 이번 시즌 월별 일정 수집

- 완료일: 2026-10-28 (Asia/Seoul)
- 목표: 한 번의 명령으로 2026-2027 시즌의 월별 공식 일정·결과 화면을 순차 수집한다.

## 변경

- `collect-season-schedule --season YYYY-YYYY` CLI 추가
- 공식 일정 화면의 이전·다음 월 버튼만 사용해 10월부터 다음 해 5월까지 렌더링
- 각 월의 표시 텍스트를 독립된 원문 스냅샷으로 보존
- 경기 카드가 없는 달도 원문 및 수집 이력을 남기되, 가상의 경기는 만들지 않음
- 월 이동 후 실제 표시된 연·월을 확인해 요청한 순서와 다르면 중단
- 화면에 노출되지 않는 내부 API, 경기 ID, 홈/원정 정보는 사용하지 않음

## 실행

```powershell
alembic upgrade head
python -m app.cli collect-season-schedule --season 2026-2027
```

## 실제 검증

공식 화면을 실제로 월 이동하며 새 SQLite DB에 수집했다.

- 일정 화면 8개월 확인 (2026년 10월~2027년 5월)
- 화면상 경기 282건 저장
- 완료 경기 41건, 예정 경기 241건 분리
- 경기 카드가 없는 화면 1개월은 원문과 수집 이력만 저장
- 단위 테스트 7건 통과
- Ruff 검사 통과

## 제약

- 이 명령은 현재 2026-2027 시즌 범위를 대상으로 검증했다.
- 홈/원정 라벨은 일정 카드에서 확인되지 않아 저장하지 않는다.
- 예정 경기·빈 달은 다음 실행 때 화면이 변경되면 갱신할 수 있다.
