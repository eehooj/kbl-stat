# 공식 팀 순위 화면 수집

- 완료일: 2026-10-28 (Asia/Seoul)
- 목표: Weekly 6 승패 예측의 기초가 되는 팀 성적을 공식 화면에 표시된 범위에서 수집한다.

## 확인한 화면

`/record/team`은 확인 시점에 표 데이터가 렌더링되지 않았다. 대신 공식 [팀 순위](https://www.kbl.or.kr/match/team-ranking) 화면에서 정규시즌 표가 실제로 표시되는 것을 확인했다.

- 시즌 선택 목록
- 순위, 팀, 승, 패, 승률, 승차
- 최근 5경기, 연속
- 홈, 원정 성적
- 다음 경기 상대, 상대전적

## 변경

- `collect-team-rankings` CLI 추가
- `team_season_standings` 테이블 및 Alembic 마이그레이션 추가
- 탭으로 분리되거나 줄로 분리된 브라우저 표시 텍스트를 모두 파싱
- 팀명 기준으로 같은 시즌의 최신 화면 관측값을 갱신
- 원문 스냅샷 및 수집 이력을 기존 테이블에 보관

## 실행

```powershell
alembic upgrade head
python -m app.cli collect-team-rankings
```

## 실제 검증

새 SQLite DB에서 실제 팀 순위 화면을 렌더링해 확인했다.

- 2026-2027 정규시즌 팀 성적 10건 저장
- 승수 범위 2~8 확인
- 단위 테스트 8건 통과
- Ruff 검사 통과

## 제약 및 다음 단계

- 표에 없는 평균 득점·실점, 리바운드, 턴오버, 공격/수비 효율은 저장하지 않는다.
- 현재는 화면의 선택된 시즌만 수집한다. 과거 시즌은 화면에서 시즌을 변경하는 동작을 별도로 검증한 뒤 확장한다.
- 다음 작업은 팀 기록의 세부 지표가 실제로 표시되는 페이지를 찾아 화면 구조를 확인하는 것이다.
