# Daily Picks 필드골 성공률 수집

- 완료일: 2026-10-30 (Asia/Seoul)
- 목표: 공개 선수 박스스코어의 필드골 성공·시도 값을 이용해 Daily Picks 필드골 성공률 문항을 비교한다.

## 변경

- 선수 경기기록에 필드골 성공(`FGM`)·시도(`FGA`)를 추가했다.
- Alembic `0015` migration을 추가했다.
- Daily Picks의 `field_goal_pct`는 최근 최대 5경기 팀 합계 성공÷시도로 계산한다.
- 양 팀 모두 최소 3경기 기록이 있어야 추천하며, 기존 수집 행에 새 값이 없으면 재수집 전까지 보류한다.

## 검증

- Ruff 검사 통과
