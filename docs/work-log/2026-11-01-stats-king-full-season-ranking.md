# StatsKing 시즌 전체 평균 기준 전환

## 목표와 완료 시각

- 목표: 최근 5경기 가중치가 시즌 전체 기록을 뒤집지 않도록 StatsKing 추천 기준을 수정하고 2026-11-01 전체 경기를 다시 추천한다.
- 완료: 2026-11-01 (Asia/Seoul)

## 변경 기준

- 기본 순위는 공식 선수 기록의 시즌 전체 누적값을 출전 경기 수로 나눈 경기당 평균 100%로 정한다.
- 시즌 전체 경기당 평균이 같은 경우에만 대상 경기 이전 최근 최대 5경기 평균을 보조 기준으로 사용한다.
- 최근 기록은 추천 설명에 계속 표시하지만 시즌 평균이 더 낮은 선수를 끌어올리지 않는다.
- 확인된 해당 날짜 결장 선수 제외와 현재 명단 스냅샷 기준은 유지한다.

## 변경 파일

- `app/services/stats_king_recommendation.py`
  - 기존 최근 5경기 60%·시즌 40% 혼합 점수를 제거했다.
  - 시즌 평균 우선, 최근 폼 동률 판정 순서로 변경했다.
- `tests/test_stats_king_recommendation.py`
  - 최근 평균이 크게 높아도 시즌 평균이 낮은 선수를 추천하지 않는 회귀 테스트를 추가했다.
- `README.md`
  - 실제 추천 기준을 시즌 전체 평균과 동률 보조 기준으로 갱신했다.
