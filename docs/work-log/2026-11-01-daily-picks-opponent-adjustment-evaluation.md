# Daily Picks 상대 허용 기록 결합 평가

## 목표와 완료 시각

- 목표: 팀 자체 평균만 비교하는 기준보다 상대 팀이 최근 같은 지표를 얼마나 허용했는지 결합하면 적중률이 개선되는지 검증한다.
- 완료: 2026-11-01 (Asia/Seoul)

## 연구 전략

각 팀의 기대값을 다음과 같이 계산했다.

```text
기대값 = 팀 자체 최근 5경기 생산 평균 50% + 상대 팀의 최근 5경기 허용 평균 50%
```

- 득점 개수형 지표는 팀·경기 합계를 사용한다.
- 필드골·3점슛 성공률은 경기별 팀 성공÷시도 비율을 사용한다.
- 벤치 득점, 세컨드 찬스 득점, 굿디펜스, 득점 우위시간도 같은 방식으로 상대 허용 값을 연결한다.
- 대상 경기와 같은 시각 또는 이후 경기는 제외한다.

## 구현 내용

- `app/services/daily_picks_recommendation.py`
  - 생산 추천과 분리된 상대 허용 조정 백테스트를 추가했다.
  - 두 전략의 평가 가능 건수·적중 수·적중률을 함께 출력한다.
- `app/cli.py`
  - `evaluate-daily-picks-strategies` 명령을 추가했다.
- `tests/test_daily_picks_strategy.py`
  - 한 팀의 자체 생산과 맞상대의 허용 평균이 정확히 결합되는지 검증한다.

## 결과

```text
팀 자체 평균: 평가 20건 / 적중 11건 / 55.0%
상대 허용 50% 결합: 평가 20건 / 적중 12건 / 60.0%
```

선택이 바뀐 5문항:

- 새로 적중: 2026-10-28 세컨드 찬스 득점
- 새로 적중: 2026-10-29 2점슛 성공
- 새로 적중: 2026-10-29 블록슛
- 기존 적중에서 실패: 2026-10-29 개인 파울
- 기존 적중에서 실패: 2026-10-30 벤치 득점

순개선은 1문항, 적중률은 5%포인트였다.

## 판단

- 상대 허용 기록은 정확도 개선 후보로 유지한다.
- 공식 정답이 20건뿐이고 50:50 비율도 아직 검증되지 않았으므로 생산 추천에는 적용하지 않는다.
- 이후 새 정답 표본에서 개선이 재현되는지 확인한 뒤 적용 여부를 결정한다.
- 같은 20건에서 가장 높은 혼합 비율을 탐색해 선택하지 않는다.
