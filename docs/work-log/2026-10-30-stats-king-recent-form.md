# StatsKing 최근 경기 폼 보정

- 완료일: 2026-10-30 (Asia/Seoul)
- 목표: 공개 선수 박스스코어가 충분히 쌓인 선수는 최근 5경기 폼을 StatsKing 추천에 반영한다.

## 변경

- 대상 경기 시작 시각보다 엄격히 이전에 끝난 공개 선수 박스스코어만 조회한다.
- 선수·팀별로 최신순 최대 5경기를 사용한다.
- 최소 3경기 이상이면 최근 경기당 평균 60%와 시즌 경기당 평균 40%를 추천 순위에 사용한다.
- 3경기 미만이면 시즌 평균만 사용한다.
- 추천 출력에 시즌 평균과 실제 반영된 최근 경기 수·평균을 함께 표시한다.

## 데이터 누수 방지

- 대상 경기와 같은 시각 또는 이후에 시작한 기록은 최근 폼 계산에서 제외한다.
- 수집된 박스스코어가 부족할 때 값을 추정하거나 미래 경기를 포함하지 않는다.

## 검증

- 단위 테스트 26건 통과
- Ruff 검사 통과

## 사용 준비

최근 폼을 사용하려면 대상 경기 전의 완료 경기 박스스코어를 먼저 모아야 한다.

```powershell
python -m app.cli collect-schedule
python -m app.cli collect-game-player-stats --limit 20
python -m app.cli predict-stats-king
```
