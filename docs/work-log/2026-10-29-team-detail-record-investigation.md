# 팀 세부 기록·경기 상세 화면 조사

- 조사일: 2026-10-29 (Asia/Seoul)
- 목적: Weekly 6 승패 분석에 필요한 평균 득점·실점, 리바운드, 턴오버, 공격/수비 효율과 홈/원정 근거를 공식 화면에서 확인한다.

## 확인한 화면

### 팀기록

- `https://www.kbl.or.kr/record/team`
- `https://www.kbl.or.kr/team/teamRecord`
- `https://promy.kbl.or.kr/record/team`

구단 서브도메인의 팀기록 화면에는 다음 선택 메뉴가 보였다.

- 시즌, 대회, 일반 기록/클러치/디펜스 대시보드/슛 대시보드 등 기록 유형
- 1차 스탯, 2차 스탯, Four Factors, Misc, 스코어링, 오퍼넌트, 디펜스 등 세부 지표 유형

하지만 실제 팀별 수치 표는 확인 시점에 계속 로딩 상태였고, 화면 텍스트에도 팀별 값이 표시되지 않았다. 대표 도메인의 동일 메뉴 경로는 표 영역 자체가 렌더링되지 않았다.

### 경기 기록 상세

- `https://www.kbl.or.kr/match/record/S49G01N4/20261004`
- `https://promy.kbl.or.kr/match/record/S49G01N4/20261004`

확인한 경기 기록 상세 경로에서는 헤더·푸터만 표시되고 경기 박스스코어, 홈/원정 라벨, 팀 세부 기록은 표시되지 않았다.

## 결정

- 팀 세부 지표 및 경기 상세 수집 코드는 추가하지 않았다.
- 화면에 표시되지 않은 값을 내부 API나 추정으로 대체하지 않는다.
- 기존 팀 순위 수집은 화면에 실제 표가 표시되므로 계속 사용한다.

## 재시도 결과

같은 구단 팀기록 화면을 새로고침한 뒤 다음 조건으로 다시 확인했다.

- 2026-2027 시즌 / 전체
- 2026-2027 시즌 / 정규시즌
- 2025-2026 시즌 / 전체

세 경우 모두 표 영역이 로딩 표시에서 완료되지 않았으며 팀별 수치가 화면에 나타나지 않았다. 따라서 이번 현상은 현재 시즌에만 한정된 문제로 확인되지 않았고, 화면 기반 수집을 시작할 근거도 아직 없다.

## 재개 조건

다음 중 하나가 확인되면 수집 구현을 재개한다.

1. 팀기록 표가 화면에 로딩되어 팀별 수치와 열 이름이 실제로 보일 때
2. 공식 일정 화면에서 연결한 경기 상세가 홈/원정과 박스스코어를 실제로 표시할 때
3. 공식 사이트가 공개적으로 안내한 다른 화면 경로에서 같은 정보가 표시될 때

재개 시에는 보이는 열 이름·값·시즌·대회 필터를 먼저 기록하고, 그 이후에만 DB 스키마와 파서를 추가한다.

## 다음 작업 제안

현재 확보된 일정 결과와 팀 순위를 이용해, 홈/원정 구분이 필요 없는 범위부터 최근 5/10경기 성적과 휴식일을 계산하는 예측 특성 기능을 구현한다. 홈/원정 및 세부 효율 지표는 위 재개 조건이 충족될 때 추가한다.
