# 공식 일정·결과 화면 수집

- 완료일: 2026-10-28 (Asia/Seoul)
- 목표: KBL 공식 일정 및 결과 화면에 실제로 표시된 경기 사실을 수집한다.

## 확인한 화면

공식 [일정 및 결과](https://www.kbl.or.kr/match/schedule) 화면에서 월별 경기 카드에 다음 값이 표시되는 것을 확인했다.

- 경기 날짜·시각
- 대회 구분
- 경기장
- 두 팀의 화면상 표기 순서
- 완료 경기의 점수와 `기록`·`하이라이트` 버튼
- 예정 경기의 `0-0` 표기와 예매·프리뷰·Challenge 버튼

화면에는 홈/원정 라벨이 보이지 않았으므로, 두 팀의 표시 순서를 홈/원정으로 해석하지 않았다.

## 변경

- `collect-schedule` CLI 추가
- 브라우저가 렌더링한 일정 화면의 텍스트만 파싱
- `visible_schedule_games` 테이블 및 마이그레이션 추가
- 완료 경기는 점수와 `final` 상태, 예정 경기는 점수 없이 `scheduled` 상태로 저장
- 경기 식별은 화면에 공식 경기 ID가 표시되지 않아 날짜·시각·대회·장소·팀 표기 순서로 만든 관측 키를 사용
- 원문 스냅샷과 수집 이력은 기존 테이블에 함께 보관

## 실행

```powershell
alembic upgrade head
python -m app.cli collect-schedule
```

로컬 Chrome과 Playwright가 필요하며, 로그인·CAPTCHA·폼 제출·내부 API 직접 호출은 하지 않는다.

## 검증

실제 렌더링 화면을 새 SQLite DB에 수집해 다음을 확인했다.

- 화면상 경기 49건 저장
- 완료 경기 41건, 예정 경기 8건 분리
- 예정 경기의 화면상 `0-0`을 결과 점수로 저장하지 않음
- 단위 테스트 6건 통과
- Ruff 검사 통과
- 빈 DB에서 Alembic 마이그레이션 후 `visible_schedule_games` 테이블 생성 확인
