# 공식 경기요약 복원 및 검증 경기 입력

- 보존된 공식 렌더링 화면을 다시 파싱해 44경기 요약을 복원했다. 외부 API 호출은 없었다.
- 이전 감사에서 대조 근거가 없던 46팀을 포함해 현재 88팀 모두 선수 득점 합계와 공식 요약 최종 점수가 일치한다.
- `backfill-game-quarters` 명령으로 다른 컴퓨터에서도 동일하게 복원할 수 있다.
- Daily Picks 기본 합계·슛 비율·특수 지표 및 상대 허용 연구 모델 모두 양 팀 득점 대조를 통과한 경기만 사용한다. 미검증 경기 때문에 표본이 부족해지면 기존 최소 3경기 기준에 따라 추천이 보류된다.
- 점수 일치는 리바운드·파울 등 모든 세부 지표의 정확성까지 증명하지 않는다. 추가적인 지표별 검증은 남아 있다.
- 검증: pytest 50 passed, Ruff 통과. 감사 88팀 불일치·누락 0팀. 기본/상대 허용 모델 모두 공식 정답 20건 중 12건 적중(60%) 유지.
- 신규 경기의 요약이 없으면 `collect-game-quarters` 또는 보존 화면 복원 후 감사가 필요하다. 이번 변경은 Daily Picks에 적용하며 StatsKing 추천 규칙은 변경하지 않았다.
