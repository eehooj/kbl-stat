# 문자중계 특수 득점 다경기 검증

## 목표와 완료 시각

- 목표: 벤치 득점·세컨드 찬스 득점 산출을 여러 실제 경기로 검증하고, 공식 선수기록과 불일치하는 벤치 득점은 저장하지 않도록 한다.
- 완료: 2026-11-01 (Asia/Seoul)

## 변경 기능과 주요 파일

- `app/services/play_by_play_collection.py`
  - 공식 선수 박스스코어가 팀 최종 득점까지 완전하게 수집된 경우, 문자중계에서 확정한 선발 5명을 제외한 득점 합계와 벤치 득점을 자동 대조한다.
  - 두 값이 다르면 해당 경기의 특수 득점을 저장하지 않고 명시적으로 실패한다.
  - 선수 이름의 공백 차이는 정규화해 비교한다.
- `tests/test_play_by_play_collection.py`
  - 완전한 박스스코어의 일치·불일치와 불완전한 박스스코어의 교차검증 보류를 테스트한다.

## 실행·검증

공식 문자중계 화면을 렌더링해 다음 5경기를 추가 검증했다.

- `S49G01N42/20261028`
- `S49G01N41/20261027`
- `S49G01N40/20261026`
- `S49G01N39/20261025`
- `S49G01N37/20261025`

앞서 확인한 `S49G01N43/20261029`를 포함해 총 6경기·12팀에서 문자중계 기반 벤치 득점과 공식 선수기록의 비선발 득점 합계가 모두 일치했다.

```bash
python -m pytest -q
# 31 passed
python -m ruff check app tests
# All checks passed!
```

로컬 DB에는 6경기·12팀의 특수 득점이 저장됐다. 추가 5경기 저장 결과는 10건, 일정 미연결은 0건이었다.

## 외부 데이터와 제한 사항

- 공식 KBL 경기기록과 문자중계의 브라우저 렌더링 화면만 사용했다. 내부 API는 직접 호출하지 않았다.
- 벤치 득점은 12팀 모두 독립적인 공식 박스스코어 합계와 대조했다.
- 세컨드 찬스 득점은 공식 별도 합계가 화면에 없어 독립 수치 대조는 여전히 불가능하다. 공격리바운드 이후 점유권 이벤트 순서를 재생하는 방식으로만 검증했다.
- 공식 선수기록 합계가 팀 최종 득점과 다르면 박스스코어가 불완전한 것으로 보고 교차검증을 강제하지 않는다.


## 남은 작업과 주의점

- 세컨드 찬스 득점은 점프볼, 공격자 파울, 자유투 마지막 시도, 연장전 등 예외 표본을 더 확인한다.
- 연장전 문자중계 탭이 존재하는 경기에서 현재 Q1~Q4 수집 범위를 확장해야 한다.
- 검증 표본을 늘린 뒤 기존 완료 경기 전체 백필 여부를 결정한다.
