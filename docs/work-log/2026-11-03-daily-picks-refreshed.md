# 11월 3일 Daily Picks 누락 경기 보완 및 민감도 비교

- 공식 일정 화면 이전 달 버튼으로 10월 일정 49건을 갱신했다. 10월 30~31일 경기가 DB에 예정 상태로 남아 있던 문제를 해소했다.
- 화면에서 발견한 경기기록 링크 N44~N47 및 기존에 확인된 11월 1일 N48의 경기요약·선수기록·문자중계를 수집했다. 총 5경기, 선수기록 107행, 팀 특수 기록 10행 갱신. 내부 API 직접 호출 없음.
- 전체 감사: 100팀의 선수 득점 합계와 공식 최종 점수 불일치·누락 0.

## 추천 재계산

| 문항 | 최근 5경기 KCC | 최근 5경기 소노 | 선택 |
|---|---:|---:|---|
| 필드골 성공률 | 50.87% | 48.41% | KCC |
| 세컨드 찬스 | 10.8 | 12.2 | 소노 |
| 벤치 득점 | 28.4 | 30.8 | 소노, 낮은 확신 |

- 필드골·세컨드 찬스는 최근 3경기·5경기·전체 이전 경기·상대 허용 모델의 선택 방향이 모두 일치한다. 이를 보정된 확률로 해석하지 않는다.
- 벤치 득점은 자체 평균 3/5/전체 모두 소노지만 상대 허용 모델에서는 KCC 31.3 대 소노 30.9로 방향이 바뀐다.
- 페인트존·속공은 미지원이므로 계속 보류한다.
- 자니 오브라이언트는 10월 30일 5분 출전 기록이 있고 11월 1일 박스스코어에는 행이 없다. 11월 1일 소노 경기의 실제 팀 기록이 이번 평균에 포함되었다. 미출전 원인은 이 사실만으로 확정하지 않는다.
- 사용자 확인 오늘 결장 영향을 임의의 감점 수치로 적용하지 않았다. 동료 출전시간·선발 변경에 따른 효과는 미확인이다.
- 이번 결과는 앞선 잠정 추천 기록을 대체한다. 생산 추천 규칙은 변경하지 않고 실제 데이터 보완과 연구 모델 비교를 수행했다.
