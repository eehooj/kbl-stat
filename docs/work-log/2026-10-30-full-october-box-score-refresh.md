# 10월 완료 경기 박스스코어 전체 재수집

- 완료일: 2026-10-30 (Asia/Seoul)
- 목표: Daily Picks의 팀 누적·최근 지표가 일부 경기 표본에만 의존하지 않도록, 공식 일정에 표시된 10월 완료 경기의 공개 선수 박스스코어를 다시 수집한다.

## 변경

- `render_current_schedule_player_records`가 경기기록 탭을 연 뒤 이전 페이지로 한 번만 돌아가던 문제를 수정했다.
  - 경기기록 탭은 같은 경기 상세 화면 안에서 전환되므로, 한 번 뒤로 가면 일정 화면이 아니라 요약 탭에 남았다.
  - 이제 각 경기마다 공식 일정 화면으로 다시 이동한 뒤 해당 경기의 `기록`과 `경기기록`을 연다.
- 공식 `2026-2027` 시즌 일정 화면 8페이지를 다시 수집해, 완료 경기 상세기록을 일정 행에 연결할 수 있게 했다.
- 공식 일정에 표시된 완료 경기 기록을 재수집했다.

## 결과

- 고양 소노: 9경기 필드골 성공/시도 기록 확보
  - 시즌 합산 필드골 성공률 45.0%
  - 최근 5경기 합산 필드골 성공률 48.4%
- 서울 삼성: 8경기 필드골 성공/시도 기록 확보
  - 시즌 합산 필드골 성공률 50.2%
  - 최근 5경기 합산 필드골 성공률 52.7%
- 따라서 10월 30일 Daily Picks의 필드골 성공률 항목은, 현재 공개 기록 기준 서울 삼성을 우선 추천할 근거가 생겼다.

## 확인한 제한

- 현재 수집하는 공개 선수 박스스코어 화면에는 필드골·2점슛·리바운드·어시스트·스틸 등은 표시되지만, 벤치 득점·세컨드 찬스 득점·덩크 성공의 팀 합계는 표시되지 않았다.
- 이 세 지표는 공식 화면에서 별도 표시 위치가 확인되기 전까지 추정값을 데이터로 저장하지 않는다.

- 공식 시즌 일정: 표시된 경기 282건 수집·갱신

- 현재 팀 소속과 과거 누적 선수 기록이 어긋나는 경우를 막기 위해 공식 로스터 기준 검증을 추가한다.
