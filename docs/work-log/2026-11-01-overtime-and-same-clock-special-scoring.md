# 연장전·동일 시각 세컨드 찬스 검증

## 목표와 완료 시각

- 목표: 세컨드 찬스 득점의 연장전, 자유투, 동일 시각 이벤트 순서와 기타 점유권 예외를 공식 문자중계로 검증한다.
- 완료: 2026-11-01 (Asia/Seoul)

## 변경 기능과 주요 파일

- `app/collectors/official_pages.py`
  - 문자중계 화면에 실제 표시된 Q1~Q4와 `EQ1`, `EQ2` 등의 연장전 탭을 동적으로 찾는다.
  - 연장전은 5번째 이후 경기 구간으로 보존한다.
- `app/services/play_by_play_collection.py`
  - 화면이 최신 이벤트부터 표시된다는 사실에 맞춰 같은 경기 시각의 여러 행도 역순으로 재생한다.
  - 계산 규칙 버전을 `visible-play-by-play-v2`로 올렸다.
- `tests/test_play_by_play_collection.py`
  - 연장전 탭 탐색, 쿼터 경계에서 세컨드 찬스 초기화, 동일 시각 공격리바운드-파울-자유투 역순 표시를 검증한다.

## 실행·검증

공식 경기 `S49G01N42/20261028`은 4쿼터까지 80-80이고 연장전 15-10이 표시된 실제 연장전 표본이다. 문자중계에는 Q1~Q4 외에 `EQ1` 탭과 내부 화면 키 `X1`이 표시됐다.

- Q1~Q4만 계산한 기존 한국가스공사 세컨드 찬스: 13점
- EQ1을 포함하되 동일 시각 순서 수정 전: 15점
- EQ1과 동일 시각 공격리바운드-파울-자유투를 모두 반영: 18점
- 원주 DB: 6점
- 벤치 득점은 24점·13점으로 공식 선수기록 교차검증과 계속 일치했다.

```bash
python -m pytest -q
# 34 passed
python -m ruff check app tests
# All checks passed!
```

기존 6경기를 새 규칙으로 다시 계산하고 5경기를 추가했다. 로컬 DB에는 총 11경기·22팀이 `visible-play-by-play-v2`로 저장됐다. 모든 팀의 벤치 득점이 완전한 공식 박스스코어 교차검증을 통과했다.

## 외부 데이터와 제한 사항

- 공식 KBL 경기기록·문자중계의 렌더링 화면만 사용했고 내부 API를 직접 호출하지 않았다.
- 11경기 화면에서 자유투 이벤트 513건, 공격리바운드 이벤트 218건을 포함한 표본을 확인했다.
- 검사한 11경기에는 `점프볼` 또는 `공격자`라는 문자중계 이벤트가 표시되지 않아 두 예외는 실제 표본으로 검증하지 못했다.
- 문자중계는 같은 시각에 자유투 성공이 위쪽, 원인이 된 파울과 공격리바운드가 아래쪽에 나타날 수 있으므로 화면 행 전체를 역순 재생해야 한다.


## 남은 작업과 주의점

- `점프볼`, 공격자 파울 또는 이에 해당하는 KBL 고유 문구가 실제로 표시되는 경기 표본을 계속 찾는다.
- 다중 연장전 경기가 생기면 `EQ2` 이상을 실제 화면으로 재검증한다.
- 세컨드 찬스 공식 합계가 화면에 별도로 제공되지 않아 독립 합계 대조는 여전히 불가능하다.
