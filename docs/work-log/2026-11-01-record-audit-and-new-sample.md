# 기록 대조 및 신규 표본 평가

- `audit-box-scores`: 선수 득점 합계와 공식 경기요약 테이블의 최종 점수를 읽기 전용으로 비교한다. 요약 미수집도 별도 검출하며 불일치·누락 시 종료 코드 1을 반환한다.
- 현재 88팀 중 42팀은 일치, 46팀은 경기요약 테이블에 대조 근거가 없다. 후자는 기록 오류로 확정할 수 없으며 추가 요약 수집 또는 보존 화면 재파싱이 필요하다. 이 감사만으로 모든 지표의 완전성이 검증된 것은 아니다.
- `evaluate-daily-picks-strategies --since 2026-11-01`: 기존 연구에 사용한 10월 28~31일 문항을 제외하고 이후 정답만 평가한다. 현재 해당 구간 정답은 0건으로 평가 불가다.
- 기존 추천 규칙 변경이나 미검증 기록의 자동 제외는 이번 단계에서 수행하지 않았다. 다음 작업은 누락된 요약 근거를 보완하고 경기 단위 검증을 추천 입력에 연결하는 것이다.
- 기존 테스트 49개 및 Ruff 통과. 외부 API 호출 없이 저장된 공식 화면 데이터만 사용했다.
