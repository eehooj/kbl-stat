# 2026-11-01 StatsKing 전체 경기 수정

## 문제와 수정 시각

- 문제: 공식 StatsKing 화면에 오늘 경기 3개가 표시됐지만 기존 수집기가 첫 경기만 저장해 한 경기 추천만 출력했다.
- 수정: 2026-11-01 (Asia/Seoul)

## 공식 화면 확인

공식 `/game/challenge/stats` 화면의 같은 날짜 아래 다음 세 경기 카드가 반복 표시됐다.

- 14:00 고양 소노 vs 수원 KT
- 14:00 창원 LG vs 원주 DB
- 16:30 서울 삼성 vs 서울 SK

## 변경 내용

- `app/services/stats_king_collection.py`
  - 현재 날짜 아래 반복되는 `참여 상태 → 시각 → 장소 → 마감 문구 → 두 팀` 구조를 모두 파싱한다.
  - 과거 주간 화면의 `Pick N → 날짜·시각 → 장소 → 두 팀` 구조도 함께 지원한다.
- `app/services/stats_king_recommendation.py`
  - 지정 날짜의 모든 경기 추천을 생성하고 경기별 결과를 렌더링한다.
- `app/cli.py`
  - `collect-stats-king`이 수집한 전체 카드 수를 출력한다.
  - `predict-stats-king --on YYYY-MM-DD`를 추가했다.
- 회귀 테스트
  - 오늘 반복 카드 3건과 과거 주간 Pick 카드 3건을 각각 모두 읽는지 검증한다.

## 데이터 제한

- 공식 KBL 브라우저 렌더링 화면에 표시된 정보만 사용했고 내부 API는 직접 호출하지 않았다.
- 공식 선택지·확률은 화면에서 확인되지 않아 현재 명단의 시즌 평균과 대상 경기 이전 저장 최근 폼으로 순위를 정했다.
- 앨런 윌리엄스는 저장된 최근 경기 표본이 3경기 미만이어서 리바운드 추천이 시즌 평균만을 사용한다.
