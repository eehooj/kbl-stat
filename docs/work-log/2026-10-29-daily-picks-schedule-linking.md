# Daily Picks 일정 연결과 화면 문구 분류

- 완료일: 2026-10-29 (Asia/Seoul)
- 목표: Daily Picks의 화면상 문제를 같은 경기의 공식 일정 카드와 근거 기반으로 연결하고, 질문 유형을 추측 없이 보존한다.

## 변경

- `daily_picks_schedule_links` 테이블과 Alembic `0008` migration을 추가했다.
- `collect-daily-picks` 실행 뒤, 저장된 Daily Picks 문제를 화면 기반 일정 카드와 자동 연결한다.
- 연결에는 다음 세 조건이 모두 필요하다.
  1. 문제의 날짜·시각과 일정 카드의 시작 시각이 같다.
  2. 화면상 장소가 같다.
  3. 일정 카드의 두 팀 이름이 세 선택지 안에서 각각 확인된다. `무승부` 같은 비팀 선택지는 팀 일치에 사용하지 않는다.
- 후보가 없거나 둘 이상이면 연결하지 않는다. 팀 표기 순서만으로 홈/원정을 정하지 않는다.
- 질문 문구에 실제로 나온 지표(`득점`, `리바운드`, `어시스트`, `스틸`, `블록`, `턴오버`, `파울`)와 `1~4쿼터` 표기만 payload의 `classification`으로 저장한다. 화면 문구만으로 분류할 수 없는 질문은 `unclassified`로 남긴다.

## 실행

```powershell
alembic upgrade head
python -m app.cli collect-season-schedule --season 2026-2027
python -m app.cli collect-daily-picks
```

## 실제 검증

별도 SQLite DB에서 2026-2027 시즌 공식 일정 화면과 현재 Daily Picks 화면을 다시 렌더링했다.

- Daily Picks 질문 5건 저장
- 다섯 질문 모두 같은 시각·장소·양 팀 선택지가 확인된 일정 카드에 연결
- 일정 화면에서 표시된 경기 282건 수집·갱신
- 질문 유형은 스틸·턴오버·블록·파울 등 확인 가능한 문구만 분류했고, 지표가 문구에 명확히 없는 항목은 미분류로 유지
- 단위 테스트 18건 통과, Ruff 검사 통과

## 아직 하지 않은 일

- 분기별 팀 기록, 선수 기록, 공식 정답 및 채점 규칙은 현재 화면 수집 범위에 없으므로 Daily Picks 추천이나 정답 예측을 생성하지 않았다.
- 마감 시각은 화면의 상대 카운트다운만으로 절대 시각을 추정하지 않는다.
- 공식 정답 공개 화면이 확인되면 결과 수집과 시점 고정 백테스트를 추가한다.
