# 공개 경기 상세 기록 화면 조사

- 완료일: 2026-10-29 (Asia/Seoul)
- 목표: Daily Picks와 StatsKing 품질 개선에 필요한 공개 경기 상세 기록의 실제 화면 구조를 확인한다.

## 확인 결과

공식 일정 화면의 완료 경기 카드 `기록` 버튼은 공개 경기 상세 URL로 이동한다.

- 예시 경로: `https://www.kbl.or.kr/match/record/S49G01N1/20261003`
- 일정 화면에는 현재 완료 경기용 `기록` 버튼 42개가 표시됐다.

경기 상세의 `경기요약` 화면에는 다음이 표시된다.

- 두 팀, 최종 점수, 경기장
- 팀별 1~4쿼터 점수와 연장전·합계
- 시즌 성적·상대전적 등 팀 비교 값

같은 공개 화면의 `경기기록` 탭에는 다음이 표시된다.

- 홈·원정 구분
- 양 팀 선수별 출전 시간
- 득점, 공격·수비 리바운드 및 합계 리바운드, 어시스트
- 스틸, 블록, 턴오버, 파울 등 박스스코어 지표
- 팀 합계 행

## 판단

- Daily Picks의 쿼터 득점·팀 기록 문제에는 경기요약의 쿼터 점수와 팀 합계 지표를 사용할 수 있다.
- StatsKing의 최근 폼에는 선수별 경기 기록을 사용할 수 있다.
- 모두 로그인이나 내부 API 없이 공개 화면에서 확인 가능한 정보다.

## 다음 구현

1. 일정 카드의 `기록` URL을 완료 경기와 연결한다.
2. 경기요약의 쿼터 점수와 경기기록의 선수·팀 박스스코어를 저장한다.
3. 선수 최근 5경기와 팀별 쿼터·팀 지표를 계산해 StatsKing·Daily Picks 추천에 반영한다.

자동 선택·응모·제출은 포함하지 않는다.
