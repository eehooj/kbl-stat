# 화면 렌더링 기반 기록 수집 전환

- 완료일: 2026-10-28 (Asia/Seoul)
- 목표: KBL 내부 API 직접 호출을 제거하고, 브라우저 화면에 표시된 정보만 저장한다.

## 확인한 화면

`/record/`는 현재 404이며, 실제 기록 메뉴는 `/record/seasonLeader`를 사용한다. 렌더링 완료 후 화면에서 다음을 확인했다.

- 시즌 선택 목록: 1997부터 2026-2027까지
- 선수기록·팀기록 등 기록 메뉴
- 시즌리더의 득점, 리바운드, 어시스트, 스틸, 블록, 슛 성공률, PER, OFFRTG 등 표시 지표

## 변경

- `api.kbl.or.kr` 직접 호출 코드와 API 기반 CLI 제거
- Playwright가 로컬 Chrome으로 KBL 기록 페이지를 렌더링하고 `body`의 표시 텍스트만 읽도록 구현
- 표시된 시즌 리더 값을 별도 `season_player_stats` 테이블에 저장
- 화면 원문과 수집 이력은 기존 원문/로그 테이블에 보관
- 화면에 없는 경기 키·선수 ID·박스스코어·정답을 유추해 저장하지 않음

## 실행

```powershell
pip install -e ".[dev]"
python -m app.cli collect-season-leaders
```

Chrome이 설치되어 있어야 하며, 로그인·CAPTCHA·폼 제출은 하지 않는다.

## 실제 검증

새 SQLite DB에 실제 시즌리더 화면을 한 번 렌더링해 수집했다.

- 화면에 표시된 시즌리더 130건 저장
- 렌더링 텍스트 원문 스냅샷 1건 저장
- 수집 로그 1건 저장
- 동순위가 있는 지표도 선수·팀 기준으로 각각 보존
