# StatsKing 공개 선수 기록 추천

- 완료일: 2026-10-29 (Asia/Seoul)
- 목표: 로그인이나 공식 게임 화면의 선택지를 사용하지 않고, 공개 선수 기록으로 StatsKing의 득점·리바운드·어시스트 후보를 추천한다.

## 확인한 화면

공식 [선수기록](https://www.kbl.or.kr/record/player) 화면에서 다음을 확인했다.

- 2026-2027 시즌의 공개 선수 기록 표
- 선수별 경기 수(`GP`), 누적 득점(`PTS`), 리바운드(`REB`), 어시스트(`AST`)
- 7페이지로 나뉜 선수 행
- 각 선수 옆에 표시된 팀 엠블럼

팀명은 행 텍스트가 아니라 화면상 엠블럼으로 표시된다. 공개 화면의 엠블럼 코드와 공식 팀명을 검증해 연결했다. 팀 표기 순서로 홈/원정을 판단하지 않는다.

## 변경

- `visible_player_season_stats` 테이블과 Alembic `0010` migration을 추가했다.
- `collect-player-records`가 공개 선수 기록 표의 모든 페이지를 브라우저로 렌더링해 경기 수·득점·리바운드·어시스트를 저장한다.
- `predict-stats-king`을 추가했다.
- 현재 StatsKing 경기 카드의 두 팀 선수만 후보로 제한하고, 득점·리바운드·어시스트별 경기당 평균이 가장 높은 선수를 추천한다.
- 로그인 프로필, 로그인 명령, 참여 화면 클릭은 제거했다. 공식 게임 선택지 수집과 자동 응모·제출은 범위 밖이다.

## 실행

```powershell
alembic upgrade head
python -m app.cli collect-stats-king
python -m app.cli collect-player-records
python -m app.cli predict-stats-king
```

## 실제 검증

별도 SQLite DB에서 현재 공식 화면을 다시 렌더링했다.

- StatsKing 경기 카드 1건 저장: 울산현대모비스 vs 부산KCC
- 공개 선수 기록 7페이지, 131건 저장
- 현재 공개 기록 기준 추천
  - 득점: 게이지 프림 (울산 현대모비스), 23.43점/경기
  - 리바운드: 숀 롱 (부산 KCC), 13.11개/경기
  - 어시스트: 허훈 (부산 KCC), 9.11개/경기
- 단위 테스트와 Ruff 검사를 통과했다.

## 제한과 다음 단계

- 이 추천은 공개 시즌 누적 기록을 경기 수로 나눈 값이다. 최근 5경기, 선발 여부, 부상·출전 정보는 아직 반영하지 않는다.
- 공식 StatsKing 화면의 실제 선택지·정답·채점 규칙을 확인하지 않았으므로 `challenge_questions`, 확률, 적중률은 만들지 않는다.
- 향후 공개 경기 상세 기록이 안정적으로 수집되면 최근 경기 가중치와 출전 가능성 정보를 추가한다.
