# StatsKing 소표본 보정 연구

- `evaluate-stats-king-shrinkage --since 2026-11-01` 추가.
- 검증된 박스스코어를 시간순으로 재생하며 같은 시작 시각의 경기는 모두 평가한 다음 기록을 추가한다. 현재 시즌 누적표를 과거 평가에 사용하지 않는다.
- 연구 보정식: (선수 누적 기록 + 이전 리그 선수-경기 평균 × 3)/(선수 경기 수 + 3). 강도 3은 연구용 고정값이며 성능을 보고 최적화하지 않았다.
- 11월 1일 9개 부문 결과는 원평균·보정평균 모두 5/9. 기존 실제 추천 4/9와 후보·입력 데이터가 다르므로 직접 성능 향상으로 비교할 수 없다.
- 과거 등록/결장 명단을 복원하지 못해 본 연구는 과거 출전 이력이 있는 선수 후보를 사용한다. 엘런슨도 후보에 포함된다. 실제 추천은 기존 등록·당일 결장 필터와 시즌 평균 정책을 유지한다.
- 경기별 DB에 윌리엄스의 대상 경기 이전 출전 기록이 없으므로 이 사례의 소표본 보정 효과는 검증되지 않았다. 과거 경기 수집 범위 보완이 우선이다.
- 미래 신규 표본 성능 검증이나 확률 보정을 완료한 것이 아니다. 보정값은 확률이 아니라 기록 평균이다.
- 단위 테스트로 소표본 보정 방향·강도 및 0경기 거부 검증. 저장된 공식 화면 기록만 사용, 내부 API 호출 없음.
