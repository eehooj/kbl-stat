# 기준 시각 기반 팀 폼 계산

- 완료일: 2026-10-29 (Asia/Seoul)
- 목표: 이미 수집한 공식 일정·결과 화면 데이터만으로 Weekly 6 승패 분석의 기초 특성을 계산한다.

## 변경

- `team_form_snapshots` 테이블 및 Alembic 마이그레이션 추가
- `compute-team-form --season YYYY-YYYY --as-of ISO-8601` CLI 추가
- 기준 시각보다 **엄격히 이전**에 시작한 `final` 경기만 계산에 사용
- 팀별로 다음 지표 저장
  - 시즌 경기 수·승·패
  - 최근 5경기·10경기 승패
  - 평균 득점·실점
  - 휴식일

## 데이터 누수 방지

- `--as-of`와 같은 시각 또는 그 이후에 시작한 경기는 계산에서 제외한다.
- 예정 경기와 점수가 없는 경기는 사용하지 않는다.
- 계산 결과는 시즌·팀·기준 시각별 스냅샷으로 저장한다.
- 휴식일은 마지막 완료 경기 다음 날부터 기준 일자 전날까지의 경기 없는 날짜 수다.

## 제한

- 일정 카드의 팀 표기 순서를 홈/원정으로 해석하지 않으므로 홈/원정 특성은 계산하지 않는다.
- 팀 세부 기록 화면의 표가 실제로 렌더링되지 않아 리바운드·턴오버·효율 지표는 포함하지 않는다.
- 동점은 KBL 정규경기에서 발생하지 않는다는 전제 아래 승·패로 계산한다.

## 실행

```powershell
alembic upgrade head
python -m app.cli collect-season-schedule --season 2026-2027
python -m app.cli compute-team-form --season 2026-2027 --as-of 2026-10-29T19:00+09:00
```

## 실제 검증

새 SQLite DB에서 공식 일정 화면을 다시 수집한 뒤 계산했다.

- 2026-2027 시즌 팀 폼 10건 저장
- 팀별 완료 경기 수 5~9경기
- 단위 테스트 10건 통과
- Ruff 검사 통과
