# Daily Picks 덩크 성공 수집

- 완료일: 2026-10-30 (Asia/Seoul)
- 목표: Daily Picks의 `덩크슛 성공` 문항을 추정이 아닌 공식 경기기록 수치로 추천한다.

## 확인

- KBL 공식 경기기록의 `경기기록` 탭 선수 박스스코어에는 `DK`(덩크 성공)와 `DKA`(덩크 시도)가 표시된다.
- 이 표는 렌더링된 공식 화면만 읽으며, 내부 API를 호출하지 않는다.

## 변경

- `visible_player_game_stats`에 nullable `dunk_made` 열을 추가했다. (Alembic `0016`)
- 공개 선수 박스스코어 파서가 `DK` 열을 저장한다.
- Daily Picks 추천 모델이 `dunk_made`를 지원한다.
- 기존에 보관한 공식 박스스코어 원문을 다시 파싱하는 `backfill-game-dunks` 명령을 추가했다.

## 검증 및 결과

- 테스트 26건 통과, Ruff 검사 통과
- 보관된 공식 박스스코어 889 선수 행의 덩크 성공 값을 갱신했다.
- 2026-10-30 고양 소노 vs 서울 삼성의 덩크 성공 문항:
  - 최근 5경기 평균: 소노 1.0회, 삼성 2.4회
  - 데이터 기반 추천: 서울 삼성

## 남은 특수 지표

- 벤치 득점과 세컨드 찬스 득점은 현재 확인한 공식 선수 박스스코어의 합계 열에 직접 표시되지 않는다.
- 문자중계의 교체·공격리바운드 이벤트를 근거로 산출할 수 있는지 별도 검증 후 구현한다.
