# Daily Picks 최근 경기 기간 비교

## 목표와 완료 시각

- 목표: 최근 몇 경기를 사용하는 것이 적중률에 유리한지 공식 과거 정답에서 누수 없이 비교한다.
- 완료: 2026-11-01 (Asia/Seoul)

## 구현 내용

- `app/services/daily_picks_recommendation.py`
  - 기존 최근 5경기 추천 계산에 경기 수 상한을 주입할 수 있게 했다.
  - 최근 3·5·10경기와 전체 이전 경기 기준을 동일한 공식 정답에 비교한다.
  - 각 문제의 대상 경기와 같은 시각 또는 이후 기록은 기존과 동일하게 제외한다.
- `app/cli.py`
  - `evaluate-daily-picks-lookbacks` 명령을 추가했다.
- `README.md`
  - 평가 명령과 작은 표본의 과적합 주의를 문서화했다.

## 결과

```text
최근 3경기: 평가 18건 / 적중 8건 / 44.4%
최근 5경기: 평가 20건 / 적중 11건 / 55.0%
최근 10경기: 평가 20건 / 적중 11건 / 55.0%
전체 이전 경기: 평가 20건 / 적중 11건 / 55.0%
```

- 최근 3경기는 평가 가능 건수와 적중률이 모두 낮았다.
- 5경기·10경기·전체 이전 경기는 현재 20문항 표본에서 같은 결과였다.
- 현재 생산 기준인 최근 5경기를 변경할 증거가 없으므로 유지한다.

## 다음 정확도 개선 후보

- 팀 자체 최근 평균뿐 아니라 상대 팀이 같은 지표를 얼마나 허용했는지 결합한 기대값을 별도 백테스트한다.
- 공식 정답 표본을 계속 누적하고 기간별 결과를 재평가한다.
- 20건 표본에 가장 잘 맞는 기간을 사후 선택해 생산 규칙을 바꾸지 않는다.

## 외부 데이터 제한

- 공식 KBL 화면에서 수집한 대상 경기 이전 기록과 공식 Daily Picks 정답만 사용했다.
- 내부 API는 직접 호출하지 않았다.
