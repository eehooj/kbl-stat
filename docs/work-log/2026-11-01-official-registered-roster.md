# StatsKing 공식 등록선수 대조

- 공식 `/player/player` 등록선수 화면 10페이지에서 185명을 수집했다. 팀과 선수명은 화면 표에서 읽었으며 내부 API는 호출하지 않았다.
- 시즌 기록표를 현재 등록 명단으로 간주하던 한계를 보완했다. StatsKing 후보는 최신 시즌 기록 스냅샷과 별도의 등록선수 디렉터리에서 이름·팀이 모두 일치해야 한다.
- 완전한 등록 명단이 없으면 후보를 추천하지 않는다. 빈 페이지나 페이지 간 중복 선수가 발견되면 수집을 중단한다.
- `collect-registered-roster` CLI 및 일일 갱신 단계를 추가했다. 완성된 명단은 RawSourceDocument에 보존한다.
- 기존 당일 결장 제외는 유지한다. 등록은 경기 당일 출전 확정을 의미하지 않으므로 출력에 미확인 상태를 명시했다.
- 추천 결과에 시즌 출전 경기 수를 추가했다. 앨런 윌리엄스의 평균 리바운드 15개는 시즌 1경기 표본이다. 시즌 평균 우선이라는 사용자 선택은 유지했다.
- 기존 테스트 50개 통과, Ruff 통과, 실제 수집 및 11월 1일 세 경기 재추천 검증 완료. 추천 선수 변경 없음.
- 남은 한계: 공식 당일 엔트리·부상 정보의 별도 수집, 등록 명단의 관측 시각 유효기간 및 과거 시점 명단 선택은 추가 구현이 필요하다. 현재 최신 명단 필터를 과거 StatsKing 성능 평가의 근거로 쓰면 안 된다.
